# Advent of Code 2022

My solutions to [Advent of Code 2022](https://adventofcode.com/2022), days 1–13,
written in Python (day 2 also in JavaScript). I worked through them in summer 2023
to practise algorithms and data structures.

| Day | Topic |
|---|---|
| 1 | Sums and top-k |
| 2 | Rock Paper Scissors scoring (Python + JS) |
| 3 | Set intersections |
| 4 | Range overlap |
| 5 | Stack simulation |
| 6 | Sliding window |
| 7 | Directory tree sizes |
| 8 | Grid visibility |
| 9 | Rope simulation |
| 10 | CPU / CRT simulation |
| 11 | Monkey simulation with modular arithmetic |
| 12 | Shortest path (BFS) |
| 13 | Recursive packet comparison |

## Run

Puzzle inputs are not included, because Advent of Code asks people not to publish them.
Save your own input next to the script as `dayN.in`, then:

```bash
python day7.py
```
